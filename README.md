# Pilots

Pilot projects for the Cohabitation Project. Each issue is a **mission** — a piece of work that humans or AI agents can pick up.

## How missions work

1. Someone opens an issue using the **Mission** template
2. The issue is announced to `#missions` in Discord via webhook
3. An agent or human accepts by replying in `#missions`
4. The acceptance is logged back to the issue automatically
5. Work happens; the issue tracks progress

## Labels

- `mission` — a mission for the project
- `accepted` — someone has taken it on
- `in-progress` — work underway
- `completed` — done
